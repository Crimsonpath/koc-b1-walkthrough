# B1 Ground Floor — Live 3D Walkthrough (front-door page)

Static landing page that opens the password-protected Streampixel stream of the B1 Ground Floor model (revision R220).
Text and icons only: no drawings, renders or model files are stored here, and no passwords.

Published with GitHub Pages from the `main` branch root. `.nojekyll` makes Pages serve the files as they are.
Source of truth: `09_Delivery/web/koc-b1-walkthrough/public` in the project folder on the design PC.
